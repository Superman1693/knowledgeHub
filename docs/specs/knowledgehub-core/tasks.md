# KnowledgeHub 核心闭环 —— 实现任务（tasks.md）

> **实现状态（2026-10-09）**：任务组 1–5 已全部实现并通过实测。
> - 后端：8 张表 + Alembic 迁移（含 HNSW / pg_trgm 索引）、文档上传解析分块索引、混合检索、SSE 流式问答、分类/标签、设置、备份恢复、健康检查
> - 前端：11 个视图（工作台 / 文档 / 详情 / 导入 / 分类 / 标签 / 检索 / 问答 / 设置 / 数据与备份 / 扩展路线图）
> - 验证：接口冒烟全部 200；端到端上传→分块→检索通过；`pytest tests -q` → 20 passed
> - 未实现：任务组 6（后续扩展）按计划留给独立 Feature Spec

> 本文件把 `requirements.md` 与 `design.md` 拆解为**离散、可勾选、可追溯**的实现任务。
> 任务格式：`- [ ] N. 任务` / `- [ ] N.M 子任务` / 末尾 `_需求：X_` 表示该任务对应需求编号。
> 任务依赖：同一任务组内默认自上而下；跨组依赖见每组开头说明。标注「可并行」的任务可同一 wave 并发执行。

# KnowledgeHub 核心闭环 —— 实现任务（tasks.md）

> **实现状态（2026-10-13 更新）**
> - **任务组 1–5（核心闭环）与任务组 6（后续扩展）均已实现并通过实测** —— 本文档曾长期标注
>   「任务组 6 未实现」，实际上三个扩展模块早已上线（共 25 个接口），本次一并更正。
> - 规模基线：后端 **85 个 OpenAPI 路径 / 15 张表 / 9 个迁移**；前端 **19 个页面**；
>   后端测试 **101 passed, 3 skipped**；前端 **19 passed**（Vitest）；
>   `vue-tsc -b` 与 `vite build` 均通过。
> - 除规格内的核心闭环外，另落地了「写入 / 关联 / 复习」三个 PKM 闭环（新建笔记与编辑器、
>   写回磁盘并重建索引、版本历史、回收站、双向链接与反向链接、知识图谱、闪卡与 SM-2 间隔复习）
>   以及附件、多级分类、每日笔记与模板、外部变更扫描、OCR、中文分词（jieba）、
>   LLM 重排序、批量摘要、批量操作、编辑冲突检测（乐观锁）、检索日期区间、
>   标签合并、启动自动扫描、回收站保留期、保存的检索条件等能力。
>   完整批次记录见 `docs/localmind-design-mapping.md`。
> - 详见 `docs/fix-report-2026-10-12.md`（缺陷修复）与 `docs/feature-gap-analysis-2026-10-12.md`（缺口盘点）。

> 本文件把 `requirements.md` 与 `design.md` 拆解为**离散、可勾选、可追溯**的实现任务。
> 任务格式：`- [x] N. 任务` / `- [x] N.M 子任务` / 末尾 `_需求：X_` 表示该任务对应需求编号。
> 任务依赖：同一任务组内默认自上而下；跨组依赖见每组开头说明。标注「可并行」的任务可同一 wave 并发执行。
